## Changelog
- 0.1.0 - First release
- 1.0.0 - Improved folder structure and dependencies
- 1.1.0 - Add support for Dataproc Serverless and quick fix for BigQuery load with schema
- 1.2.0 - Fix packaging (1.0.0 and 1.1.0 shipped without subpackages), require debussy-airflow 0.0.7+ (installable again), add package summary, add airflow_easy_setup and Dataproc Serverless support
- 2.0.0 (unreleased) - Package renamed from `debussy_concert` to `debussy` (import `debussy`, environment variable prefix `DEBUSSY__`). Requires Python 3.11+ and Airflow 3.4+; the debussy-airflow and airflow-dbt dependencies are replaced by operators and hooks in debussy itself. DAG parameter `schedule_interval` is now `schedule`, and templates use `logical_date` and `data_interval_end`. Airflow code lives in `debussy.backends.airflow` (`AirflowService`, the start and end motifs, the BigQuery, Dataproc and dbt operators and the reverse ETL hooks). Airflow, Google Cloud, dbt, MySQL and SFTP dependencies are now extras: `pip install "debussy[airflow,gcp,dbt]"`. `airflow_easy_setup` and the per-pipeline setup files are replaced by one generic loader, `debussy.backends.airflow.load_dags`, for YAML (`composition_type` and `os_env_prefix` keys) and Python pipelines. A `ConfigRdbmsDataIngestion` built in Python now gets the default PySpark script, which fixes the Python-API ("yamless") example. New engine-neutral task contract in `debussy.core.tasks` (`TaskSpec`, `RunContext`, `Capability`, `ActionRegistry`), not yet used by the motifs; Jinja2 is now a core dependency. The `bigquery_ingestion_incr` example uses `logical_date.strftime('%Y%m%d%H')` for its partition, because its `macros.ds_format` template failed on Airflow 3.
